# Bố cục 3 cột bằng Bootstrap Grid và Flexbox

Mở index.html trong trình duyệt có Internet. Sử dụng Bootstrap 5.3.3 và Font Awesome 6.5.2 qua CDN.

## Nội dung thực hành

1. Row chứa 3 col-md-4; dùng d-flex justify-content-center align-items-center để căn giữa. Từ 768px có 3 cột, nhỏ hơn xếp dọc.
2. Section dùng container my-5 py-3 để điều chỉnh khoảng cách.
3. d-none d-md-block: thông báo chỉ hiện từ 768px.
4. Carousel có 3 ảnh SVG lưu cục bộ, indicators và nút trước/sau; tự chuyển mỗi 6 giây.
5. Font Awesome: icon nhà ở tiêu đề và máy bay giấy trên nút Gửi.
6. Form: họ tên, email, nội dung; kiểm tra required và định dạng email.

Form hợp lệ hiển thị thông báo minh họa, không gửi hoặc lưu dữ liệu vì chưa có backend.

Ảnh nộp bài: desktop.png, mobile.png. Mã nguồn: index.html, style.css, script.js và images/.
